# BC Staff kernemodul

Version 0.1.0 POC for Drupal 11.

Efter git pull: `drush en bc_staff -y`.

Ruter: `/staff` (overblik) og `/staff/min-status` (egen status).

Tildel rettighederne *Se BC Staff medarbejderoverblik* og *Opdater egen BC Staff-status* under `/admin/people/permissions`. De tildeles ikke automatisk til anonyme brugere.

Dette er en udviklings-POC: lokation er indtil videre fri tekst, og overblikket er en tabel uden fotos, grupper eller touch-identifikation. Brug kun fiktive testbrugere, indtil persondataadgang og visningsregler er afklaret.
